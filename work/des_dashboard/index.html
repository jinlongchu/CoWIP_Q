Measurement notes and controls

Each step calls the original environment and advances simulation time by 10 minutes. Playback changes the request frequency only, not the processing distributions, rewards or decision interval. Each machine shows the actual job being processed; each assembly stage has two parallel machines. The 720-minute warm-up is excluded from the output count and control-period metrics. Buffers may already contain parts at the start.

Throughput uses a 120-minute rolling window. The rolling reference changes gradually after a target change, so it may differ from the current target. System WIP includes both matching buffers, with each assembly kit counted as two component equivalents. Reducing a cap does not remove jobs already in process, so actual WIP may temporarily exceed the new cap.

This page shows one run with one seed, not the multi-seed averages reported in the paper. Switching policies or changing conditions during a run marks it as a custom experiment. Reset with the same seed to compare policies and export the resulting CSV files. Existing checkpoints are loaded for inference only; no network parameters are updated.
